## 文脈で残す所

置き換える語でも、次の文脈では今の語を残す。

| 語 | 残す文脈 |
|---|---|
| 往復 | パラパラなどアニメの再生 |
| 最近傍 | 点の近傍探索 |
| 見出し | レポートや文書の見出し |
| 押す | キーを押す、押したまま、スタンプ |
| 区画・領域 | 1 つの文書で「区画」と「領域」を別の物として定義している所。置き換えると 2 つの語が同じになる |
| 操作の記録・操作ログ | 2 つが別のディレクトリやファイルを指している所 |
| 中継 | コードのコメントやメッセージが「中継」と書いている所。文書の語はコードの語にそろえる |
| 掃いた所 | 図のラベルと対応している所 |
| 写し方 | 写像の意味 |
| 幹・芯 | スケルトンの部位 |
| 筋 | 画面に表示される縞 |
