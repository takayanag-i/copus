# copus

カタカナ語がふつう使われる所を和語や漢語の造語で書いた箇所を見つけ、コーパスで一般的な言い方を確かめてから置き換える Claude Code のスキル。

## 置き換えの例

| 今の語 | 置き換え |
|---|---|
| 画素 | ピクセル |
| 道具 | ツール |
| つまみ | スライダー |
| 当てはめ | フィッティング |
| 裏のスレッド | ワーカースレッド |

決めた語の一覧は [references/terms.csv](references/terms.csv) にある。置き換える語、残す語、文脈によって残す所を1つの表に並べ、根拠の数と数え方を列に持つ。

## 入れ方

このリポジトリの中身を `.claude/skills/copus/` に置くと、Claude Code から `/copus` で呼び出せる。

`scripts/terms.py` には `pip install fugashi unidic-lite` が要る。

## 決め方

| 項目 | 内容 |
|---|---|
| 比べる単位 | 単語だけでなく、例:「ボタンをクリック」と「ボタンを押」のように使う場面の句で比べる |
| 数え方 | コーパスごとに、句を含む記事とページの数の割合を取る。割合は、そのコーパスでの件数が多いほど強く効かせて平均する |
| 重み | UI の文言、ウェブの処理の言い方、説明の文の3つの文脈ごとに、コーパスの重みを [references/weights.csv](references/weights.csv) で決める。システム開発の語に合わせ、wiki を軽く、システム開発の文書とドメイン固有のコーパスを重くしている |
| 置き換える語 | 組の中の加重シェアが 0.6 以上で、根拠の数が足りる語 |
| 残す語 | 加重シェアが割れた語、根拠の数が足りない語、置き換え先が同じ文書で別の物を指す語 |
| コードとの対応 | 文書がコードを説明しているときは、コードのコメントやメッセージの語にそろえる |

手順は [SKILL.md](SKILL.md) にある。

## コーパス

基本のコーパスは次の6つで、いつも数える。

| コーパス | 数えるもの | 向き |
|---|---|---|
| Wikipedia 日本語版 | 句を含む記事の数。API の完全一致検索 | 漢語の学術用語に寄る |
| MDN | 句を含むページの数 | ウェブとブラウザの処理の言い方 |
| OpenTelemetry | 句を含むページの数 | ログ、トレース、計測の言い方 |
| PostgreSQL 文書 | 句を含むページの数。英語の原文のコメントを除く | データベースと SQL の言い方 |
| Kubernetes 文書 | 句を含むページの数 | インフラとコンテナの言い方 |
| Python 文書 | 句を含むページの数。訳文だけを数える | 言語と標準ライブラリの言い方 |

`bash scripts/fetch_corpora.sh <フォルダ>` で取得して作る。

### ドメイン固有のコーパス

対象の分野の文書を、利用者が指定したときだけ足す。例: その分野の製品のマニュアル、規格の訳、学会の用語集。

```bash
python3 scripts/build_corpus.py <名前> <文書のフォルダ> <コーパスのフォルダ> --domain
CORPUS_DIR=<コーパスのフォルダ> python3 scripts/corpus_count.py --pairs pairs.tsv --context prose --domain <名前>=<重み>
```

`--domain` を付けて作ったコーパスは、数えるときに名前を指定した場合だけ使われる。
